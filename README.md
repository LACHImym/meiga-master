# 🎨 アートクイズ

名画の4択クイズ（全5問・100点満点）のブラウザアプリ。**正式名称: 名画MASTER — 世界の有名絵画クイズ**（2026-07-17リブランド）。

## ブランドアセット（らちさん制作・正本は `1x/` フォルダ）

| ファイル | 用途 |
|---------|------|
| `1x/og_card.png` → `og-card.png` | Xシェア用OGPカード（1201×631） |
| `1x/ロゴ.png` → `logo.png` | ヘッダーロゴ（名画MASTER） |
| `1x/キュビコン.png` → `favicon.png` | ファビコン・アイコン（真珠の耳飾りの少女モチーフ） |

アセットを更新したら `1x/` に上書き→同名でコピーし直す。`gen-og-card.py` は旧下書きツール（og-card-draft.pngに出力・正式カードは上書きしない）。

⚠️ **Wikimedia Commonsのサムネイルは決まったサイズしか使えない**（250/330/500/960/1280pxなど。900px・400pxなどは400エラー）。画像URLを触るときは必ずこのサイズから選ぶこと。

**公開時に index.html の og:image を絶対URL（https://〜/og-card.png）に差し替える**。

⚠️ **ロリポップは静的ファイルに7日キャッシュ（max-age=604800）を付ける**。そのため index.html は `style.css?v=YYYYMMDD` / `app.js?v=…` / `works.js?v=…` とバージョン番号付きで参照している。**CSS・JS・データを更新したら、index.html内の3つの `?v=` の日付を全部同じ新しい日付に変えること**。これで全訪問者が待ち時間なく新版を取得する（index.html自体は長期キャッシュされないので即伝播）。

## ファイル構成

| ファイル | 役割 |
|---------|------|
| `index.html` | ページ本体 |
| `style.css` | 見た目（ニューモーフィズム／ソフトUI。デザイントークンは design_handoff_nest_smart_home.zip 準拠：--bg #e6e9ef・--panel #eef1f6・ティール #2dd4bf・アンバー #f59e0b・二重ソフトシャドウ・Inter） |
| `app.js` | クイズのロジック（出題・採点・シェア） |
| `works.js` | 出題データ（Notion「DB作品リスト」から書き出したコピー） |

## 出題データの自動更新（完全自動パイプライン）

本番サイト（lachiart.com/quiz/meiga/）は **works.js を GitHub Pages から読み込む**（index.html のローダー参照。読めなければ同梱 works.js にフォールバック）。よって**データ更新はロリポップへのアップロード不要**——GitHubに push すれば最大10分以内に全員へ反映される。

- `scripts/generate-works.mjs` … Notion「DB作品リスト」から新作を取り込み works.js に追記（既存作品のレベル・解説は保持／新作は暫定 level:2／安全検証つき）。要 `NOTION_TOKEN`。
- `.github/workflows/update-works.yml` … 毎朝5時JST（cron `0 20 * * *`）にGitHubのクラウドが自動実行→変更あればコミット→Pages再配信。手動実行も可（`gh workflow run "出題データ自動更新（毎日）"`）。
- **一度だけ必要な設定**: リポジトリのGitHub Secretに `NOTION_TOKEN`（Notion内部インテグレーションのトークン）を登録し、DB作品リストをそのインテグレーションに共有。以降は無人で回る。
- 新作の暫定レベルは2。適宜「レベルを見直して」で再調整する。

## 出題データの手動更新方法（従来）

Notionの「DB作品リスト」が正本。クイズには **PD=可・PD画像URLがWikimedia Commons直リンク・作家名とタイトルあり** の作品だけを書き出している。

**更新の合図**: Claudeに「**クイズのデータを更新して**」と言う
→ Notionを再集計して `works.js` を作り直し、公開済みならそのまま反映する。

## レベル（Level 1〜・拡張可能）

各作品の `level` は日本での知名度基準でClaudeが付与している。表記は「Level N」＋★の数。

- **Level 1（★）** … 教科書級の超有名作（モナリザ・叫び・ニケ等）
- **Level 2（★★）** … 美術好きなら知っている（オランピア・忘れえぬ女等）
- **Level 3（★★★）** … マニア級（モンドリアン初期作・ルーヴルの渋い名品等）

**レベルボタンはworks.jsのデータから自動生成**——`level: 4` の作品を足せば「LEVEL 4」ボタンが勝手に現れる。
出題は選択中のレベルのみから、ハズレ選択肢は全プールから選ぶ。選んだレベルはブラウザに記憶される。
**データ更新時の運用**: 新しく増えた作品には、書き出しのタイミングでClaudeがレベルを付与する。

## クイズの仕組み

- 1回5問。作家単位でシャッフルするので同じ作家に偏らない
- 出題タイプは「作者当て」「タイトル当て」の2種（作者不詳の作品はタイトル当てのみ）
- ハズレ選択肢は同じ時代グループ（古典／19世紀／前衛）から優先して選ぶ
- 紛らわしいタイトル同士（例: コンポジションⅦとⅧ）は同時に出さないガード付き
- 画像はCommonsの縮小版（900px）を読み込み、失敗時は原寸にフォールバック

## 公開

GitHub Pages想定。リポジトリにpush → Settings > Pages で公開。
独自ドメイン（サブドメイン）はGitHub Pagesのカスタムドメイン設定＋DNSのCNAMEで接続する。
